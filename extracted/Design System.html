Design System

The token + component specification behind the operations dashboard. Dark-mode-first, warm-neutral surfaces, a single themeable emerald accent, and tabular monospace for every number. Built to Tailwind conventions.

v1.0 Dark-first Geist / Geist Mono Tailwind-ready WCAG AA text

Principles

Six rules keep the surface calm under heavy daily use.

1 · Dark, warm-neutral base
Three near-black surfaces (bg, surface, surface-2/3) stack by elevation. Whites and blacks carry a faint warm tone; saturation stays under 0.02.
2 · One accent, used sparingly
Emerald marks the primary action, focus, and positive data — nothing decorative. It is the only themeable hue; semantic colors never recolor.
3 · Numbers are monospace
Every figure, ID, and money value uses Geist Mono with tabular-nums + slashed zero so columns align and digits don't jump.
4 · Hairline structure
Separation comes from 1px alpha-white borders and elevation, not heavy fills. Shadows are deep and soft, never spread.
5 · Dense but breathable
Stripe-tight by default; a data-density attribute swaps compact / comfy by changing row height and gutter only.
6 · Motion is a whisper
Entrances are a 6–10px slide over ~280ms. No opacity-from-zero traps, no looping decoration; honors prefers-reduced-motion.

Spacing

A 4px grid. Component padding and flex/grid gap draw from the same scale; never use ad-hoc margins between sibling UI elements — lay them out with gap.

Page gutter is the density-aware --pad (22px regular · 16px compact · 28px comfy). Card padding 18px. Section rhythm 16px between cards, 24px between titled blocks.

Tailwind setup

Two files ship with this system. Link the tokens once; merge the theme into your Tailwind config. Semantic colors stay fixed — override only --accent* for theming.

tailwind.config.js ds-tokens.css 
// 1 — link tokens at the app root (resolves the CSS variables)
<link rel="stylesheet" href="ds-tokens.css" />

// 2 — merge the theme
module.exports = { presets: [require("./tailwind.config.js")] };

// 3 — compose with semantic classes
<div class="rounded bg-surface border border-line p-4.5 shadow">
  <p class="text-md font-semibold text-content">Revenue</p>
  <p class="font-mono text-display text-content tabular-nums">$318,420</p>
  <span class="text-positive text-caption font-semibold">▲ 12.4%</span>
</div>
Theming: swap the brand hue by resetting --accent, --accent-2, --accent-ink and the three alpha derivatives on :root (or a scoped class). Emerald, blue, amber and violet presets ship in the app's tweak panel. Density: set data-density="compact|comfy" on a container to rescale row height and gutter.
